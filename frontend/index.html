Telegram

Шаг 1. Добавьте бота в администраторы канала

Откройте Telegram, найдите бота @mytelegram5_bot и добавьте его в администраторы вашего канала с правом публикации сообщений.

Шаг 2. Укажите ссылку на канал

Скопируйте ссылку вида https://t.me/имя_канала и вставьте её в поле ниже, затем нажмите «Подключить Telegram».

Бот должен быть администратором канала

Discord

Шаг 1. Добавьте бота на сервер

Нажмите кнопку ниже, выберите свой сервер и авторизуйте бота.

Добавить бота на сервер
Шаг 2. Получите ID канала:
  1. В Discord включите Режим разработчика (Настройки - Дополнительно)
  2. Кликните правой кнопкой по каналу - Копировать ID
  3. Вставьте ID в поле ниже
  4. Нажмите "Подключить Discord"
ID канала (18+ цифр), куда будут публиковаться посты
